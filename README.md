# Pravoúhlý trojúhelník

Kalkulačka pravoúhlého trojúhelníku do školy (VŠCHT). Zadáš dvě známé veličiny přímo do polí u trojúhelníku a zbytek se dopočítá i s postupem: výchozí vztah, obecný vzorec, dosazení a výsledek.

**Otevřít:** https://vojtech3k.github.io/pravouhly-trojuhelnik/

- pole pro a, b, c, α, β jsou přímo u stran a vrcholů náčrtu
- náčrt jde otáčet (90°, posuvník, tažení myší), zrcadlit a položit přeponou dolů
- další veličiny: výška na přeponu, úseky přepony, obsah, obvod a sklon (%, 1 : m)
- kopírování postupu jako Markdown + LaTeX (do Obsidianu)
- jeden soubor `index.html` bez závislostí, funguje i offline

Značení: pravý úhel je u C, přepona c, odvěsna a leží proti α, odvěsna b proti β.

Zadání, podle kterého appka vznikla, je v [PROMPT.md](PROMPT.md).
